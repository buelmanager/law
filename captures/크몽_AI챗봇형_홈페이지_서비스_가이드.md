## 💡 차별화 포인트

기존 챗봇 서비스는 **챗봇만 제공**하지만, 우리 서비스는 **챗봇 + 홈페이지를 함께 제공**
- 랜딩페이지 + AI 챗봇 통합
- 반응형 웹 디자인
- SEO 최적화
- 빠른 배포 (Vercel/HuggingFace)

## 📝 서비스 설명 (크몽 등록용)

### 제목
**AI 챗봇 통합 홈페이지 제작 - 24시간 자동 상담 랜딩페이지**

### 한 줄 소개
비즈니스에 딱 맞는 AI 챗봇이 탑재된 세련된 홈페이지를 제작해드립니다.

### 상세 설명

#### 🎯 이런 분께 추천드립니다
- **서비스업 사장님**: 24시간 고객 문의 응대가 필요한 분
- **프리랜서/전문가**: 포트폴리오 + 상담 예약이 필요한 분
- **스타트업**: 제품/서비스 소개 + 고객 상담 자동화가 필요한 분
- **병원/학원/부동산**: 자주 묻는 질문 응대를 자동화하고 싶은 분
- **쇼핑몰 운영자**: 제품 문의 대응을 효율화하고 싶은 분

#### 🌟 서비스 특징

**1. 세련된 디자인**
- 모던한 다크/라이트 테마
- 글래스모피즘 UI
- 부드러운 스크롤 애니메이션
- PC/태블릿/모바일 완벽 대응

**2. AI 챗봇 통합**
- 홈페이지에 자연스럽게 녹아든 챗봇 UI
- 방문자 질문에 24시간 자동 응답
- 상담 예약/문의 연결 가능
- 대화 맥락 이해 (GPT 기반)

**3. 빠른 로딩 & SEO**
- Next.js 기반 최적화
- 검색엔진 최적화 (SEO)
- Google Analytics 연동 가능

**4. 무료 호스팅**
- Vercel 무료 호스팅 설정
- SSL 인증서 자동 적용
- 커스텀 도메인 연결 지원

#### 🔧 기술 스택
- **프론트엔드**: Next.js, React, TypeScript, Tailwind CSS
- **애니메이션**: GSAP, Lenis Smooth Scroll
- **챗봇**: GPT API / Groq API
- **호스팅**: Vercel (무료)
- **AI 백엔드**: HuggingFace Spaces (무료)

#### 📋 제작 가능한 홈페이지 유형
- 기업/회사 소개 페이지
- 서비스 랜딩페이지
- 포트폴리오 사이트
- 제품 소개 페이지
- 예약/상담 서비스 페이지
- 교육/강의 소개 페이지

#### 💡 포함되는 섹션 (예시)
- Hero (메인 배너 + 챗봇)

## 🔄 수정 정책

### 수정 가능 시점
- **작업물 발송 후 ~ 구매 확정 전**까지

### 수정 횟수
| 패키지 | 수정 횟수 |
|--------|----------|
| STANDARD | 1회 |
| DELUXE | 2회 |
| PREMIUM | 3회 |

### 수정 가능 범위
다음 항목은 **수정 범위에 포함**됩니다:
- ✅ 텍스트 내용 수정 및 교체
- ✅ 이미지 단순 교체 (동일 위치, 동일 크기)
- ✅ 버튼 텍스트/색상 변경
- ✅ 페이지 내 기존 요소의 순서 변경
- ✅ 챗봇 응답 문구 수정 (기존 시나리오 내)
- ✅ 색상/폰트 미세 조정
- ✅ 오타 및 버그 수정

### 수정 불가 범위 (추가 개발 필요)
다음 항목은 **새로운 기능 추가**에 해당하여 별도 견적이 필요합니다:
- ❌ 새로운 페이지 추가
- ❌ 새로운 기능/모듈 추가
- ❌ 챗봇 시나리오 추가 (패키지 한도 초과)
- ❌ 결제/회원가입 등 백엔드 기능 추가
- ❌ 디자인 컨셉 전면 변경
- ❌ 외부 API/서비스 연동 추가

### ⚠️ 중요 안내
> **수정 범위는 사전 협의된 사항에 한합니다.**
>
> 작업물 전달 후, 의뢰인과 긴밀하고 원활한 소통을 통해 **사전에 협의가 되었던 사항만** 수정 범위에 포함됩니다.
>
> 그 외 사항(새로운 기능 추가, 대폭 변경 등)은 수정 범위에 해당되지 않으며, 의뢰인이 원하실 경우 **추가 개발 건으로 별도 견적을 산출**하여 진행해야 합니다.
>
> 원활한 작업 진행을 위해 **초기 요구사항 협의 단계에서 충분한 소통**을 부탁드립니다.
