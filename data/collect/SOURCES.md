데이터 수집 소스 안내

우선 수집 대상으로 선택한 방대한 공식 원천:

- 국가법령정보센터 (국가법령정보센터 / law.go.kr)
  - 법령 전문(조문), 조문별 메타데이터, 시행일 등 풍부한 메타데이터 제공
  - 공공데이터로 활용 가능하며 갱신이 비교적 자주 이루어짐
  - 수집 방식: Open API 사용(가능한 경우), 필요하면 HTML 파싱(스크래핑)로 보완

- 대법원 판례(대법원 종합법률정보)
  - 판례 전문(판시사항, 판결요지, 이유), 판례번호, 선고일 등
  - 판례 수집 시 출처(판례번호) 명확히 저장 필수
  - 대량 판례가 필요하면 공식 제공 데이터 덤프나 기관 협의가 필요할 수 있음

주의사항

- API 키 및 이용 약관 확인: 일부 기관은 API 키 또는 사용 제한을 둘 수 있습니다.
- 크롤링 시 robots.txt 및 서비스 약관을 준수하세요.
- 판례/법령 텍스트는 공공저작물인 경우가 많지만, 특정 포맷/메타데이터는 재사용 정책을 확인하세요.

다음 단계

1. `data/collect/collect_labor_laws.py` 실행하여 샘플 수집

```bash
python data/collect/collect_labor_laws.py
```

2. 수집된 `data/collect/labor_laws.jsonl`을 `data/process`의 `DocumentChunker`로 청킹하고 임베딩 생성
