렌터카로 사고 났는데 휴차료를 내라고 해요

2024.02.05 7분 읽기
사연

한** 씨(29세)는 제주도 여행 중 렌터카를 빌려 운전하다 가드레일을 긁는 단독사고를 냈습니다. 렌터카 업체에서 수리비 150만원 외에 "휴차료" 80만원을 추가로 청구합니다. 자차보험에 가입했는데도 휴차료는 보상이 안 된다고 합니다. 반드시 내야 하나요?

휴차료란?

휴차료(영업손실)란 차량이 수리되는 동안 렌터카 업체가 해당 차량을 영업에 사용하지 못해 발생하는 손해입니다.

휴차료 산정 기준
  • 일일 렌트비 x 수리 기간
  • 예: 일일 렌트비 10만원 x 수리 8일 = 휴차료 80만원
  • 실제 영업 가동률 적용하는 경우도 있음

휴차료는 법적으로 인정되는 손해인가요?

네, 인정됩니다. 민법상 불법행위로 인한 손해배상에는 적극적 손해(수리비)뿐 아니라 소극적 손해(일실이익)도 포함됩니다.

대법원은 영업용 차량의 휴차손해를 인정하고 있으며, 렌터카도 영업용 차량이므로 휴차료 청구가 정당합니다.

렌터카 보험의 종류

1. 기본 보험 (의무)

  • 대인배상: 상대방 부상/사망 보상
  • 대물배상: 상대방 차량/재물 손해 보상

2. 자차보험 (선택)

  • 차량손해: 렌터카 자체 수리비 보상
  • 면책금: 보통 20~50만원 자기부담금

3. 완전자차보험 / Super CDW

  • 면책금까지 면제
  • 일부 업체는 휴차료도 면제
자차보험 ≠ 휴차료 면제

일반 자차보험은 수리비만 보상합니다. 휴차료, 면책금은 별도입니다. "완전자차" 또는 "Super CDW"를 가입해야 휴차료가 면제되는 경우가 많습니다. 계약 전 반드시 확인하세요.

휴차료를 줄일 수 있는 방법

1. 계약서 확인

렌터카 계약서에 휴차료 조항이 어떻게 되어 있는지 확인하세요. 일부 업체는 휴차료 상한을 정해둔 경우도 있습니다.

2. 적정 수리 기간 확인

휴차료는 합리적인 수리 기간에 대해서만 인정됩니다. 수리가 지연되었다면 그 이유가 정당한지 확인하세요.

  • 부품 수급 지연: 정당한 사유
  • 업체 사정으로 지연: 부당
  • 수리 대신 차량 방치: 부당

3. 실제 영업손실 증명 요청

렌터카가 항상 100% 가동되는 것은 아닙니다. 비수기에는 가동률이 50~70%인 경우도 있습니다. 실제 가동률에 따라 휴차료가 감액될 수 있습니다.

4. 대차 가능 여부

렌터카 업체가 동급의 다른 차량으로 영업할 수 있었다면, 실질적 손해가 없으므로 휴차료가 줄어들 수 있습니다.

한** 씨 사례 분석

업체 청구: 수리비 150만원 + 휴차료 80만원 = 230만원

검토 포인트

  1. 자차보험 내용 확인: 수리비 150만원 중 면책금만 부담, 나머지는 보험 처리
  2. 휴차료 면제 여부: Super CDW 미가입이면 휴차료 본인 부담
  3. 수리 기간 적정성: 8일이 합리적인지 확인
  4. 실제 가동률: 비수기였다면 감액 가능
협상 전략
  • 수리비 견적서, 수리 기간 확인
  • 실제 가동률 자료 요청
  • 휴차료 30~50% 감액 협상 시도
  • 합의 시 "일체의 채무 없음" 확인서 받기

상대방 과실 사고인 경우

만약 한** 씨가 상대방 과실로 사고를 당했다면 상황이 달라집니다.

  • 수리비: 상대방 대물보험에서 지급
  • 휴차료: 상대방 대물보험에서 지급
  • 한** 씨 부담 없음

이 경우 렌터카 업체는 상대방 보험사에 직접 청구하게 됩니다.

렌터카 이용 시 주의사항

  1. 보험 내용 꼼꼼히 확인: 자차, 완전자차, Super CDW 차이
  2. 휴차료 면제 조항 확인: 계약서에 명시되어 있는지
  3. 출발 전 차량 상태 촬영: 기존 흠집 기록
  4. 사고 시 즉시 업체 연락: 신고 의무 위반하면 보험 면책
  5. 음주/무면허 금지: 이 경우 모든 보험 면책

정리

  • 휴차료는 법적으로 인정되는 손해
  • 일반 자차보험은 휴차료 미보상
  • 완전자차/Super CDW 가입 시 면제 가능
  • 적정 수리 기간, 실제 가동률로 감액 협상 가능
  • 상대방 과실이면 상대방 보험에서 부담
